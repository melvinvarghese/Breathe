# Breathe prototype v2

Open `index.html` in a modern browser. It is a standalone static page with no build step, backend, API, external font, image dependency or package requirement.

## Included
- Optional three-cycle introductory breathing guide
- Six visual categories
- Searchable and filterable library with 24 starter exercises
- Focused practice view with adjustable session length
- Light/dark theme toggle
- Reduced-motion and keyboard support

## Files
- `index.html` — entire prototype
- `DESIGN.md` — visual system, interactions and limitations
- `README.md` — this file

## Important
Exercise instructions are illustrative starter content, not medical advice. Review content and safety guidance before public launch.
